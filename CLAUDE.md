# Development Notes

## Architecture

### Shared Header & Footer
The header and footer are **not** duplicated in HTML files. They are generated by `js/components.js` and injected into placeholder `<div>` elements (`#site-header`, `#site-footer`).

- **To edit the header or footer**, modify `js/components.js` only
- The script auto-detects page depth (`/products/`, `/bespoke-pages/`) for correct relative paths
- It auto-applies the active nav class based on the current page filename
- Loaded synchronously in `<head>` to prevent flash; fires a `componentsLoaded` event for `main.js`
- `components/` folder files are reference copies, not loaded at runtime

### JavaScript
- `js/main.js` — all interactive behaviour (carousel, mobile menu, scroll effects, product gallery, stockists map, reveal animations). Wrapped in an `init()` function that waits for `componentsLoaded`
- `js/components.js` — header/footer generation and injection

### CSS
- Single stylesheet: `css/styles.css`
- Uses CSS custom properties for spacing:
  - `--section-pad: 80px` (desktop section padding)
  - `--section-pad-mobile: 48px` (mobile section padding)
  - `--grid-gap: 24px` (grid/card gaps)

### Responsive Breakpoints
- Desktop: default styles
- Tablet: `max-width: 1024px`
- Mobile: `max-width: 768px`

## Key Conventions

### Homepage Hero
- Desktop: 720px height, overlay layout (text over image with gradient)
- Tablet: 520px height
- Mobile: auto height, **stacked layout** — text on top (order: 1), image below (order: 2), white gradient blending them via `::before` pseudo-element on `.hero picture`. Never use overlay on mobile.

### Spacing
All section padding should use CSS variables, not hardcoded values:
- Page-hero desktop: `calc(var(--section-pad) * 1.5)` top / `var(--section-pad)` bottom
- Page-hero tablet: `calc(var(--section-pad) * 1.25)` top / `calc(var(--section-pad) * 0.8)` bottom
- Page-hero mobile: `var(--section-pad)` top / `var(--section-pad-mobile)` bottom

### Mobile Carousel
The `.carousel-wrapper` uses `margin-right: -20px` to extend past container padding, with `padding-right: 20px` on the track. This prevents cards being clipped at the screen edge.

## Naming

"Exclusives" was renamed to **"Bespoke"** across the site (April 2026):
- Files: `bespoke.html`, `bespoke-pages/bespoke-*.html`
- Nav and visible text all say "Bespoke"
- **CSS class names still use `exclusives`** (e.g. `.exclusives`, `.exclusives-intro`) — this is intentional to avoid breaking styles

## File Structure
```
index.html              — Homepage
about.html              — About page
collections.html        — Collections page (includes Leaflet map)
bespoke.html            — Bespoke decorations catalogue
trade.html              — Trade/wholesale page
bespoke-pages/          — Bespoke sub-category pages
products/               — Individual product pages (~167 files)
components/             — Reference HTML templates (not loaded at runtime)
css/styles.css          — Single stylesheet
js/components.js        — Shared header/footer generator
js/main.js              — All interactive behaviour
assets/                 — Images and static assets
```
